# Wireframes

These files show the placement and the look of the homepage parts. They do not give exact measurements.

The component looks are specified in `docs/design-system/component-system.md`. Build from that spec. The specs in `docs/design-system/` win over the wireframes.

Known differences: the wireframes show rounded corners (no radius, DR-87), ফ্যাক্টচেক (removed, DR-18), চীন as a category or first region tab (DR-19), and 4-up story rows (DR-44). Follow the specs.
